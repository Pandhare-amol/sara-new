# Human-like behavior

Sara remains an AI assistant and never presents herself as human. These settings
control the visible interaction style and recovery preferences; they do not
change permissions or confirmation requirements.

Open **Settings → PC control & safety → Human-like behavior**:

- **Observe and verify actions** keeps the post-action observation preference on.
  Sara's safety-critical verification is always retained.
- **Smooth mouse movement** uses the real Windows cursor and a short eased curve.
  Longer durations are more visible; shorter durations are faster.
- **Pause when you take control** lets the existing input arbiter yield when the
  user moves the mouse or types.
- **Natural typing pauses** favors readability over speed where a typing tool
  supports an interval.
- **Stuck-action limit** controls when repeated failures should switch strategy
  and ask for help (2–5, default 3).
- **Concise progress updates** keeps narration short while a task runs.

The emergency stop, permission engine, confirmation dialogs, CAPTCHA/MFA/login
boundaries, and sensitive-action restrictions are not disabled by these
preferences. Protected desktops and inaccessible applications still require
manual user action.
